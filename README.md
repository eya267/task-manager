# Task Manager

A web-based To-Do List application developed with Java and Spring Boot.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed using checkboxes
- Filter tasks by status (All, Open, Completed)
- Save tasks permanently in a database
- Responsive user interface

## Technologies

- Java
- Spring Boot
- Spring Data JPA
- Thymeleaf
- HTML & CSS
- H2 Database
- Maven

## About the Project

This project was developed to gain practical experience
in Java backend development and web application development.

The application helps users organize their daily tasks
through a simple and user-friendly interface.

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Run TaskManagerApplication.java.
4. Open http://localhost:8080 in your browser.
